# Correlation-Adaptive-LSTM-for-Multi-factor-Stock-Return-Forecasting
Proposed Correlation-Adaptive LSTM to enhance stock return forecasting by incorporating inter-stock correlations

- analysis.ipynb: The code to conduct correlation, SNR, MSE, IC Analysis
- feature_importance_analysis.ipynb: The code to conduct  feature importance Analysis
- main - ensemble.py: The code to run the ensemble model
- main independent.py: The code to run the independent model
